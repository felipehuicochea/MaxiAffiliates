# MaxiAffiliates para BTCPay Server

Plugin de programa de afiliados para BTCPay Server (2.4.5 o superior): enlaces de referido, comisiones sobre facturas pagadas y renovaciones de suscripciones, y pagos a afiliados mediante los pagos (pull payments) de BTCPay.

**Estado: en desarrollo (hitos M1–M9 terminados: afiliados, atribución, comisiones, pagos, panel de afiliados, inglés y español, revisión de seguridad, callback de confirmación de pedidos). Versión candidata 1.0.0, aún no publicada.**

English: [README.md](README.md).

Entorno de desarrollo: ver [DEV.md](DEV.md) (en inglés). Notas de diseño: [docs/DESIGN.md](docs/DESIGN.md) (en inglés). Integración con tu sitio web: [docs/INTEGRATION.es.md](docs/INTEGRATION.es.md). Guía para afiliados: [docs/AFFILIATE_GUIDE.es.md](docs/AFFILIATE_GUIDE.es.md).

## Idiomas
Inglés y español (latinoamericano neutro). El plugin agrega sus textos en español al diccionario «Spanish» de BTCPay (lo crea si no existe). Selecciónalo en Configuración del servidor → Traducciones; instala ahí también el paquete de idioma español de BTCPay para traducir el resto de BTCPay.
